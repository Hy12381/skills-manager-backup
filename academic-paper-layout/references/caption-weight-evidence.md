# 图表字重的核验记录

核验日期：2026-10-28。用途是说明不同期刊图题、表题、表头可能使用不同字族与字重，不建立通用的「必须加粗」标准；模板更新后需重新核验。

## 官方模板

1. 《计算机学报》网站首页当前链接的 Word 投稿模板。官网模板地址：http://cjc.ict.ac.cn/wltg/new/submit/CJC-Templet_Word2003.doc 。本轮通过官网链接下载，133120字节，可由 Microsoft Word 正常打开。
   - 第2页、Word段落64：示例「图X 图片说明」，宋体，Bold=0。
   - 第2页、段落66：示例「表X 表说明」，明确写明「表说明采用黑体」，中文黑体，Bold=0。
   - 第2页、表格第一行：示例表头中文宋体，Bold=0。这里的第一行才是已确认的表头。
   - 说明：页码和段落索引属于本次下载版本，不用于其他文稿。
2. 《软件学报排版样例2025年版》。官网资源地址：https://www.jos.org.cn/uploadfile/news_images/jos/2026-04-02/软件学报排版样例2025年版.doc 。本轮重新访问官网，完整字体分析使用当日先前已下载、可正常打开的3027456字节副本；重新下载超时产生的残缺文件未用于分析。
   - 图1等图题：中文宋体，Bold=0。
   - 表1、表2、表3的「表」字采用黑体，编号采用加粗西文，标题正文中文宋体常规。它与《计算机学报》的整条中文表题黑体不同。
   - 对比表的第一行方法列名有粗体，但 Target 列名为常规字重。因此不能据此推导「表头必须全部加粗」，也不能推导「表头绝不能加粗」。

## 实际论文页面

3. 刘文炎、沈楚云、王祥丰等：《可信机器学习的公平性综述》，DOI 10.13328/j.cnki.jos.006214。官网全文：https://www.jos.org.cn/html/2021/5/6214.htm 。本轮检查已保存的24页PDF版，第3页表1及图1：图题中文为SimSun常规；表题的标签和数字与标题正文有不同字体/字重；「符号」「描述」表头为SimSun常规。该PDF页码是文件页码，不能混作正式期刊起止页。
4. 范卓娅、孟小峰：《算法公平与公平计算》，《计算机研究与发展》，2023，60(9)，DOI 10.7544/issn1000-1239.202220625。本轮检查已保存的19页PDF版，第2页表1及第4页图1：表题中文使用黑体类字形(FZHTK)，表头使用宋体类字形(FZSSK)，图题中文使用宋体类字形。黑体类字形的PDF字体标志未必含bold位，故仅看flags不足以判定视觉字重。

## 本次课程论文的选定方案

没有指定目标期刊，本轮明确选用《计算机学报》模板作为图表字重参照，而非混用各期刊细节：图题保留现有宋体并取消额外Bold；表题中文采用黑体且不额外Bold；表头保留现有宋体并取消额外Bold。字号、正文、数值、三线表和引用跳转均保留。选用此方案不表示先前所有加粗均违反学术规范，而是修正无明确依据的一刀切加粗，使结构强调更克制且有可核验依据。
