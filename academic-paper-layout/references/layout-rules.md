# 版式规则与任务参数

## 读取要求后形成参数表

只记录与本次任务有关的参数，不要求用户填完一张问卷。可从文件、模板和前文推断的直接采用。

| 参数 | 决策方式 |
|---|---|
| 字体字号、行距、纸型、页边距、单双栏 | 当前明确要求或模板；已有稿无新要求时保持 |
| 封面、页眉页脚、页码起点 | 官方封面及当前认可版本；不让正文页码重新污染封面 |
| 标题、作者、机构、摘要、关键词及英文对应项 | 模板优先；不凭空添加作者、单位、基金或英文摘要 |
| 引用制式与编号顺序 | 目标要求；顺序编码制才检查首次出现顺序，作者年份制不能按此重编号 |
| 链接维护方式 | 只补跳转用静态 anchor；会持续增删且要求自动编号时选域或文献管理器 |
| 本次修改范围 | 链接、格式、结构或正文；只做获授权的范围 |

## 标题和摘要

- 主标题默认居中，不靠空格找中心；长题目自然换行，两行均衡，避免只剩一两个字。
- 副标题不是必备部分。有必要且模板允许时保留，不为了模仿顶会人为添加。
- 封面题目与正文题目一致；保留封面需要作者填写的空项。
- 中文默认摘要标签如「摘　要：」与摘要正文同行；正文两端对齐、无首行缩进，关键词单独一段。具体字距、标签粗细及语言按模板。
- 不将「摘要」「关键词」「参考文献」自动算进正文连续编号。是否居中以及是否有编号遵循指定体例。
- 只改格式时保留摘要原文；不得把结论或实验数字改成更漂亮的结果。

## 章节与正文

- 使用真实段落样式标明层级，而不只用加粗模拟。相同层级的编号、缩进、间距一致。
- 中文技术论文无相反要求时，标题左对齐；正文两端对齐，首行缩进一致。不要把一级标题普遍居中。
- 不因「结构像顶会」就机械补齐相关工作、消融、显著性检验等段落。章节应回答论文真实研究问题；实验类论文的实验设置、结果、分析和必要消融均需要真实材料。
- 标题与后文保持关联；图表密集页避免把所有段落连成一个不可分页的巨块。检查孤立标题、单行孤段、页底题注和大块空白。

## 图、表与公式

- 默认次序：正文首次称引 → 图 → 图题 → 图注；正文首次称引 → 表题 → 表 → 表注。期刊双栏浮动排版允许合理浮动，以模板为准。
- 图片段落、图题段落居中；表格及表题居中；注释左对齐。题注从正文中单独识别，不能把「图2以……展示」这类句子当成图题。
- 图题与对应图尽量同页。表题与首行同页；跨页大表按模板重复表头并标明续表，不能为了不跨页把文字缩到难读。
- 正文中图号、表号、题注编号、链接目标一致；序列完整且无重复。正文不要出现「如上图」而无法唯一定位。
- 不把来源文献中的「原文表4」链接到本稿表4；外部出处作为文献引用单独处理。
- 表格为可编辑表，单位在表头或表注中明确。数值精度按原数据及既有稿保留，不能为对齐改数字。三线表不要求每一数据行都加线。
- 保留 OMML/其他原生公式结构，检查字母上下标、求和上下限、分式和公式编号。新公式一般居中、编号右侧；既有正确且获认可的方案可保留。

## 图题、表题与表头的字重

- 将三者作为独立格式参数，先读模板正文和真实示例的字体/字重；不可用统一的「标题与首行全加粗」规则替代。题注居中与题注加粗是两个不同属性。
- 无指定模板时，可采用中文计算机论文的克制方案：图题常规字重、表题用适当的标题字族区分、表头常规字重；边线和位置负责结构区分。只有选定参照体例且本次字体要求允许时，才采用图题宋体、表题黑体、表头宋体这一具体组合，不把字族、字号写成不可覆盖的默认。
- 黑体常规字重已具有视觉强调，不自动再施加 Bold。宋体加粗与黑体不是同一种排版；字号不同、截图缩放也会影响粗细判断。
- 某些期刊或作者会加粗方法列名、特定表头或最优结果；这可能合法。必须区分全表结构样式和有明确含义的强调，不能顺手删掉表体的最优值或统计强调。
- 第一行不一定是表头：合并标题、多级表头、续表行需按真实结构识别。加粗或取消加粗仅作用于已确认的目标行/单元格。
- 核验依据和差异见 [caption-weight-evidence.md](caption-weight-evidence.md)；来源样例是特定期刊体例，不代表所有中文论文或所有 CCF-A 会议的统一要求。

## 参考文献

- 文献编号与文献正文起点分开处理，用悬挂缩进保证多行条目对齐；具体缩进宽度随编号位数和模板。
- 段内 DOI/网址不能越出版心；不通过手工插入空格修改 DOI。URL 自动链接与正文到文后条目的内部链接分别验证。
- 上标和平排无普适唯一答案。已有正确格式时保留，不给内部链接自动套蓝色或下划线。
- 明确引用身份后才能重排文后顺序；更新所有正文、表内、图注与脚注中的引用。不能仅替换看见的普通段落。
- 文献真实性、元数据准确和引文是否支持对应论点分别核查。全文无法访问只核对到元数据时，标明范围。

## 证据与视觉验收

- 格式合规检查以指定模板和实际页面为依据，不能只参考一张期刊截图。
- 保存一份轻量改动记录：原稿哈希、目标文件、关键格式参数、对象数量、文本/数据保全结果、Word跳转结果、PDF链接结果及页面预览位置。
- 只改链接时容许渲染器微小字形差异，但要检查新增链接边界导致的自动中西文间距和换行变化。不得未经比较宣称逐像素一致。
- 审计不是提交正文的一部分；对用户只报告真实执行过的检查。
